# Snatch the Stickman — Original 3D Source Pack

This folder contains original production-source assets for Snatch the Stickman.

- `snatch-world-props-v1.blend` — editable Blender source.
- `snatch-world-props-v1.glb` — portable export.
- Asset set: rarity vault pod, transit terminal, bounty/contract board, and rare freight cargo beacon.
- Built at meter scale with low-poly geometry and portable Principled materials.
- These files are source assets, not fake Roblox asset IDs. They must be imported/published through Roblox Studio before any MeshPart asset IDs are referenced by game code.
- Gameplay collision and authoritative interactions remain Roblox-native so visual mesh iteration cannot break heist logic.
